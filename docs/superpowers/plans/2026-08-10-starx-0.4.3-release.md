# StarX 0.4.3 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (\`- [ ]\`) syntax for tracking.

**Goal:** Update the StarX implementation version to \`0.4.3\`, document the SkinsRestorer compatibility improvements already present in the working tree, and produce a locally verified Universal JAR without changing historical release records or deploying it.

**Architecture:** The root \`build.gradle.kts\` remains the single implementation-version source. Gradle propagates that value to all subprojects and generates the Velocity and Paper/Folia descriptors during the Universal assembly. Current operator-facing documentation and release metadata will reference \`0.4.3\`; prior release notes and evidence remain historical snapshots.

**Tech Stack:** Java 21, Gradle 9.6.1, Shadow JAR, JUnit 5, Velocity/Paper/Folia descriptors, GitHub Actions release metadata.

### Changed

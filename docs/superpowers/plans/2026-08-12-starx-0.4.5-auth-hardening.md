# StarX 0.4.5 Authentication Hardening Plan

> **For agentic workers:** Execute the checked tasks in order with test-first verification. Preserve unrelated dirty-worktree changes.

**Goal:** Permanently close the remaining authentication compatibility gaps and release StarX 0.4.5 with evidence-backed local verification.

**Architecture:** Keep the connection UUID as the session key and resolve the durable account from the session username when the platform changes UUIDs. Route local and UniAuth-verified passwords through the same risk/TOTP/web-approval decision path. Represent remote authentication outages with a stable user-facing service-unavailable result so they cannot be mistaken for credential failures.

**Tech Stack:** Java 21, Gradle Kotlin DSL, JUnit 5, SQLite test repositories, Velocity/Paper universal assembly.

# StarX 1.1.15

Release asset: `starx-universal-1.1.15.jar`

## CPU and runtime resource control

- Cache CrossServer TAB ping capacity and online state for 30 seconds; coalesce concurrent probes and reconcile on metadata changes.
- Start player latency sampling only when `%starx_ping%` or `%starx_ping_raw%` is referenced.
- Schedule website heartbeats and texture synchronization once per due time, and cancel replaced texture timers.
- Reclaim idle HTTP worker threads after one second.
- Add regression coverage for ping caching, latency task gating, scheduling, and worker reclamation.

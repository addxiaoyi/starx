# StarX 0.5.0

`starx-universal-0.5.0.jar`

## 稳定版变更

- 管理 API 按 UUID 归属处理账户查询、绑定、处罚、投票、皮肤和删除请求，避免同名账户之间发生参数串用。
- 账户擦除与 `COMPLETED` 状态写入合并到同一数据库事务；完成标记失败时，已擦除的数据会整体回滚，避免删除任务重试误删重新注册的账户。
- 收紧跨设备挑战、外部身份、会话替换和连接队列的 UUID 生命周期校验，避免旧连接异步结果污染新连接。
- 保留 `starx_account_deletions` 执行状态记录，供异步删除器完成任务，不在擦除阶段提前删除任务记录。

## 验证

- Common 与 Velocity 测试门禁通过。
- Universal JAR 的版本、双平台描述符、单一 API 副本和类边界由发布校验验证。
- `AUTOMATED_VERIFIED` 仅表示自动化门禁；生产部署、真实服务器和客户端验收仍需单独执行。

## 部署

将同一份 `starx-universal-0.5.0.jar` 放入 Velocity、Paper/Folia 各自的 `plugins/` 目录，保留旧 JAR 备份后完整重启对应 JVM。不要使用 `/reload` 或同时保留旧的分端 JAR。

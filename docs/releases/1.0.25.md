# StarX 1.0.25

认证界面新增正版引导：当服务器安装了 FastLogin、而当前连接没有通过正版校验时，StarX 会提示玩家在服务器内输入一次 `/premium`。

这条引导来自 FastLogin 的真实逻辑：FastLogin 对数据库中已存在且记录为离线的用户名不会再发起 Mojang 校验，只有 `/premium` 能把该记录翻回正版偏好，之后的登录才会请求加密验证并最终免密。命令由 FastLogin 后端插件提供，权限默认对所有玩家开放。

引导只在 FastLogin 可用且当前连接未通过校验时显示；FastLogin 缺失、状态未知或校验失败都不会放行，仍然走密码认证。

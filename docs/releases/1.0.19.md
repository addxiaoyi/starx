# StarX 1.0.19

下载附件：`starx-universal-1.0.19.jar`。

本版修复玩家转服、认证限流、队列反馈和跨服 TAB 映射的并发与恢复问题。

- 四个转服入口（大厅命令、管理员发送、普通队列、智能队列）使用插件持有的同一协调器，单玩家单飞和每节点 32 个在途请求上限跨入口生效。
- 每个请求独立持有连接 future 和节点名。取消先确定结果，再取消底层 future，防止取消被误报为失败、旧请求清理新请求、节点计数重复释放。
- 异步异常与超时计入失败，取消只统计一次。P50/P95/P99 从同一份最多 256 条已结束请求耗时快照计算；成功率为成功 /（成功 + 拒绝 + 失败），未知为 -1，取消及重复请求不进入该比率。
- 全局监听断线，按 Player 实例核对请求归属，旧连接断线不会取消新连接的请求。停用某模块只取消该入口的请求，插件关闭后拒绝新请求。
- /sxhub status 显示实际进行中的转服目标；/sxhub cancel 仅取消大厅请求。取消 future 是尽力取消，不能撤销 Velocity 已完成的网络连接，提示不再保证当前连接一定不变。
- 登录限流将次数、过期和容量检查原子化，防止并发提交超额通过。保持原来的认证流程与聊天框密码/TOTP 输入方式。
- 连续队列失败每 15 秒仍能收到一次反馈，不再因每次失败重置冷却而永久静默；取消/重复请求不发送子服故障提示，断线和成功转服清理提示缓存。
- cross-server-tab.yml 使用安全 YAML 构造器和严格字符串映射校验。错误结构、重复键或短暂删除保留上一份有效映射，同一失败状态只告警一次；恢复有效文件后自动加载。使用 servers: {} 可明确清空映射。

- 跨服 TAB 停用时取消周期与延迟任务，等待当前刷新退出后清理；重新启用后，旧周期的回调不能再次写入列表。

回归覆盖取消回调顺序、超时、旧连接隔离、256 次并发转服竞争、跨模块实例共享、登录限流并发、提示冷却、无效配置恢复和 TAB 停用竞态。这些是自动化模拟测试，不能代替真人跨服或千人在线验收；本次没有增加玩家网络探测。

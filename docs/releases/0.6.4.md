# StarX 0.6.4

StarX 0.6.4 聚焦跨服展示、皮肤兼容、配置升级和运行时性能。

## 下载

```text
starx-universal-0.6.4.jar
release-manifest.json
SHA256SUMS
```

同一个 `starx-universal-0.6.4.jar` 可放入 Velocity、Paper 和 Folia 的 `plugins/` 目录。生产部署时使用固定文件名 `starx-universal.jar`，并完整重启代理及所有后端，不要使用 `/reload`。

## 变更

- TAB/玩家列表复用跨服人数快照，减少重复调度、网络请求和静态内容发送。
- 任意子服可显示全网人数、当前子服人数和在线子服列表；`player-list.server-aliases` 可将真实子服键映射为中文显示名。
- PAPI 支持读取节点内存占用等运行数据，解析使用缓存快照，避免占位符高频触发网络请求。
- 网站未绑定角色时优先回退正版玩家名称皮肤；有效的第三方皮肤站 authlib-injector 纹理继续保留并应用。
- 旧单文件配置和分片配置会自动迁移并补全新增配置项。

## 升级注意

保持 Velocity 与所有 Paper/Folia 子服使用同一版本 JAR。正版在线模式仍需允许服务器访问 Mojang 服务；离线/皮肤站网络应使用受信任的现代转发和匹配的 forwarding secret。

`AUTOMATED_VERIFIED` 仅表示自动化发布门禁通过；生产停服、备份、部署和客户端皮肤验收仍需单独完成。

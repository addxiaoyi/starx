# StarX 1.1.9

Release asset: `starx-universal-1.1.9.jar`

## Skin apply reliability

- `/sxskin apply <catalog-id>` performs the website mutation on the bounded skin worker instead of the Velocity event thread.
- A refresh requested while the login lookup is running is queued and executed once after the current lookup completes.
- Apply refreshes use the bound Minecraft UUID first, avoiding stale or ambiguous username lookups.
- The change does not add polling or a background scan; skin network work still happens only on login or an explicit apply/refresh request.

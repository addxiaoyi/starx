# StarX 1.1.4

## Deployment reliability

- The self-hosted six-server deploy downloads the release asset and SHA-256 manifest through the GitHub API.
- Deployment no longer depends on the `gh` CLI being installed on the production runner.
- The release job still verifies the artifact, backs up each target, and atomically replaces the JAR serially.

## Release files

```text
starx-universal-1.1.4.jar
SHA256SUMS
release-manifest.json
```

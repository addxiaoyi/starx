# StarX 0.5.2.1

`starx-universal-0.5.2.1.jar`

## 安全修复

- **YAML 加载器加固**：限制 YAML 文档与集合中的别名数量（`setMaxAliasesForCollections(100)`），防止通过深度嵌套的 YAML 或别名循环触发的内存/CPU 放大（YAML BOMB）攻击。影响所有从文件系统加载配置的入口（`starx-common` 的 `ConfigLoader`、Velocity 端的 `ConfigLayout`）。

## 验证

- Common 与 Velocity 测试门禁通过。
- Universal JAR 的版本、双平台描述符、单一 API 副本和类边界由发布校验验证。
- `AUTOMATED_VERIFIED` 仅表示自动化门禁；生产部署、真实服务器和客户端验收仍需单独执行。

## 部署

将同一份 `starx-universal-0.5.2.1.jar` 放入 Velocity、Paper/Folia 各自的 `plugins/` 目录，保留旧 JAR 备份后完整重启对应 JVM。不要使用 `/reload` 或同时保留旧的分端 JAR。

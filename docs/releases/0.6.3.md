# StarX 0.6.3

**版本**: 0.6.3
**发布日期**: 2026-08-31

## 安全更新

- 网站皮肤档案仅允许配置网站自身域名和 `textures.minecraft.net` 的 HTTPS 纹理地址。
- `/sxskin url` 仅接受 Mojang 官方纹理 CDN 地址，避免将任意网络地址广播给玩家客户端。
- 关闭没有终端用户身份验证的自助账户删除 HTTP 接口；管理员删除接口继续受敏感 API 认证保护。
- 登录时仅保留可解析、包含 HTTPS `SKIN` URL 的第三方皮肤站档案。

## 发布文件

本地构建和生产部署的文件名为 `starx-universal.jar`。GitHub Release 工作流会将其复制为下列版本化下载附件：

```text
starx-universal-0.6.3.jar
SHA256SUMS
release-manifest.json
```

## 部署说明

将下载的 `starx-universal-0.6.3.jar`，或生产部署生成的 `starx-universal.jar`，替换到 Velocity、Paper/Folia 对应的 `plugins/` 目录，完整重启服务器。不要使用 `/reload`，也不要同时保留旧版本 JAR。

## Mojang 公钥请求超时

`Failed to request yggdrasil public key` 指向 `https://api.minecraftservices.com/publickeys` 时，报错由 Velocity 使用的 Minecraft Authlib 产生，StarX 无法从插件代码中接管该请求。

正版在线服应保持 `velocity.toml` 的 `online-mode = true`，放行运行 Velocity 的主机到 `api.minecraftservices.com:443` 和 `sessionserver.mojang.com:443`；需要代理时，把 `-Dhttps.proxyHost` 与 `-Dhttps.proxyPort` 加到 Java 启动参数并重启代理。

离线或皮肤站服应在 **Velocity** 设置 `online-mode = false`，再配置现代转发和匹配的 forwarding secret。仅把 Paper 的 `server.properties` 改成离线模式不能解决这个错误，也不能把正版认证失败安全地降级为成功。

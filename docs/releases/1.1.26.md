# StarX 1.1.26

Release asset: `starx-universal-1.1.26.jar`

## Runtime resource hardening

- Reduce idle TAB refresh wakeups when no animations are active.
- Cancel automatic update tasks during plugin shutdown and startup rollback.
- Bound EventBus, WebsiteSync, server HTTP, and HTTP API work with explicit metrics.
- Return `503 server_busy` for saturated non-health HTTP API requests.
- Skip unchanged CrossServer TAB reconciles using roster fingerprints and dirty-state signals.
- Reclaim idle HTTP deadline threads.

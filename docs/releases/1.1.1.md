# StarX 1.1.1

## Skin bridge completion

- UUID-first website profile lookup and exact UUID identity validation.
- Website-triggered online refresh is scoped to one online player and uses the existing authenticated admin API.
- No periodic player scan or full-server skin refresh was added.
- Website profile cache invalidation is keyed by UUID.
- Unsigned but trusted texture URLs remain available when the website cannot generate a MineSkin signature; the plugin does not treat a missing signature as a reason to discard an otherwise valid texture profile.
- The protected refresh endpoint accepts `player_uuid` and returns an explicit `accepted` state.

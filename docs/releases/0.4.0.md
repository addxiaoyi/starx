# StarX 0.4.0

0.4.0 是认证、网站同步、在线人数和跨版本兼容性增强版本，公共扩展 API 仍为 1.0.0。

## 功能

- 邮箱验证码统一为六位数字，游戏内输入和邮件挑战服务使用同一规则。
- 已注册玩家可在认证流程中请求一次性网页登录审批链接。
- 已验证的网站绑定可参与可信设备自动认证；未验证的 UniAuth 账号只能迁移已有本地档案。
- 网站节点上报公开在线人数能力，heartbeat 调度具备幂等启动、失败恢复和明确错误日志。
- MOTD 在线人数优先汇总后端实际连接数，避免显示异常虚假人数。
- SkinsRestorer 支持字符串和对象形式的皮肤标识；数据库时间字段兼容历史存储格式。

## 兼容范围

- Java 21、25

- Paper/Folia 1.21.0–1.21.11
- Paper/Folia 26.1.x–26.2.x
- Extension API 1.0.0

## 升级

将 Velocity 和所有 Paper/Folia 实例替换为同一份 `starx-universal-0.4.0.jar`，完整重启后确认 Velocity 健康接口、后端 heartbeat、网站节点状态和 `StarX backend ready`。

同一实例不要同时放置 `starx-universal.jar` 与旧的 `starx-velocity.jar` 或 `starx-server.jar`。

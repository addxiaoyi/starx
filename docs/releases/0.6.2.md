# StarX 0.6.2

**版本**: 0.6.2
**发布日期**: 2026-08-31

## 修复内容

- 修复 Velocity 玩家登录时 TabList 模块抛出 `plugin is not registered` 的问题。
- 延迟登录刷新任务现在使用已注册的 `StarxVelocityPlugin` 作为调度 owner。

## 发布文件

```text
starx-universal-0.6.2.jar
SHA256SUMS
release-manifest.json
```

## 部署说明

将 `starx-universal-0.6.2.jar` 替换到 Velocity、Paper/Folia 对应的 `plugins/` 目录，完整重启服务器。不要使用 `/reload`，也不要同时保留旧版本 JAR。

# StarX 1.0.15

下载附件：`starx-universal-1.0.15.jar`

## 玩家体验与网络开销

- 全网玩家继续可在任意子服 TAB 中互相看见，名称前显示 `cross-server-tab.yml` 映射后的子服名称。
- 玩家 Ping 小幅波动不再触发条目删除和重建；只有变化达到 5ms 才原位更新延迟。
- 登录、转服、断线引发的 TAB 刷新会自动合并，避免突发事件创建重复任务。
- 后端覆盖代理 TAB 条目时会由低频巡检自动恢复，模块停用后不会有延迟任务重新写入。
- 同服玩家沿用原生 TAB 条目并原位增加子服前缀，避免重复 UUID；停用模块不会把同服玩家从 TAB 移除。
- 映射配置损坏时保留上一份有效配置，并抑制同一损坏版本的重复读盘和日志。

## 可靠性

- 后端心跳状态始终包含命令接受、投递、拒绝和待投递计数，包括真实零值。
- 队列超时门禁跟随统一转服协调器，继续保证异步、限时、单飞和节点并发保护。

## 验证

- 运行 Velocity 编译、测试编译、定向测试和发布元数据校验。

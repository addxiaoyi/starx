## ✨ 新功能

### 🧩 扩展系统 (Extension System)

StarX 0.6.0 引入了完整的扩展系统，允许开发者创建自定义的扩展来扩展 StarX 的功能。

#### 核心组件

| 组件 | 描述 |
|------|------|
| `ExtensionDependencyChecker` | 自动解析扩展依赖关系，检查版本兼容性，验证加载顺序 |
| `ExtensionHotReloadManager` | 支持在不重启服务器的情况下动态重载扩展 |
| `ExtensionCompatibilityManager` | 提供平台兼容性检查、API兼容性检查、版本冲突检测 |
| `ExtensionConfigurationHelper` | 类型安全的配置访问、范围限制、枚举转换、配置验证 |
| `ExtensionCommandRegistrar` | 命令注册、别名管理、权限控制、Tab补全 |
| `ExtensionDependencyManager` | 依赖关系管理、循环依赖检测、版本冲突报告 |

#### 扩展开发特性

- **自动依赖解析**: 自动检测和加载扩展依赖
- **热重载支持**: 无需重启服务器即可重载扩展
- **兼容性检查**: 自动检查平台兼容性和API兼容性
- **类型安全配置**: 提供类型安全的配置访问方式
- **命令注册**: 简化的命令注册和管理
- **依赖管理**: 自动检测循环依赖和版本冲突

### 🎨 标签页动画系统 (Tab Animation System)

全新的标签页动画系统，为玩家提供更丰富的视觉体验。

#### 动画类型

| 动画类型 | 描述 |
|----------|------|
| `FlowingAnimation` | 流动动画，支持自定义速度和方向 |
| `PulseAnimation` | 脉冲动画，支持自定义频率和强度 |
| `ScrollingTextAnimation` | 滚动文字动画，支持自定义速度和方向 |
| `GradientAnimation` | 渐变动画，支持多种颜色渐变效果 |

#### 动画特性

- **自定义速度**: 每种动画都支持自定义速度控制
- **自定义方向**: 支持多种方向选项
- **颜色渐变**: 支持从一种颜色渐变到另一种颜色
- **循环播放**: 所有动画都支持循环播放
- **自定义内容**: 支持自定义动画显示内容

### 🖼️ 标签页图片系统 (Tab Image System)

支持在标签页中嵌入图片，为玩家提供更丰富的视觉体验。

#### 图片类型

| 类型 | 描述 |
|------|------|
| `Base64TabImage` | 通过Base64编码的图片 |
| `UrlTabImage` | 通过URL加载的图片 |

### 📊 标签页管理系统 (TabList Management System)

完整的标签页管理系统，提供灵活的标签页定制能力。

#### 核心组件

| 组件 | 描述 |
|------|------|
| `DefaultTabList` | 默认标签页实现 |
| `TabListRegistry` | 标签页注册表 |
| `TabListManager` | 标签页管理器 |

#### 特性

- **动态更新**: 支持动态更新标签页内容
- **玩家绑定**: 每个玩家可以有独立的标签页
- **事件监听**: 支持监听玩家登录/登出事件
- **自动刷新**: 支持自动刷新标签页

## 🔧 技术改进

### 代码重构

- **TabPlayerEntry接口**: 将内部接口移至 `TabList` 内部类，提高了代码封装性
- **BuiltEntry记录**: 将 `BuiltEntry` 从记录类改为普通类，解决了方法名与记录组件名冲突的问题

### Bug修复

| 问题 | 修复方案 |
|------|----------|
| `GradientAnimation.debugString()` 方法调用错误 | 改用 `LegacyComponentSerializer` 进行序列化 |
| `ExtensionConfigurationHelper` 缺少导入 | 添加 `List` 和 `Map` 导入 |
| 泛型类型擦除导致的编译错误 | 修复 `getEnum` 方法的泛型处理 |
| `TabListModule` 事件监听器接口错误 | 改用匿名类的方式注册事件监听器 |
| `DatabaseConfig` 构造函数参数不匹配 | 更新测试代码中的构造函数调用 |

## 📝 升级指南

### 从 0.5.x 升级到 0.6.0

#### 1. 更新版本号

在 `build.gradle.kts` 中更新 StarX 版本：

```kotlin
dependencies {
    implementation("io.github.addxiaoyi:starx-velocity:0.6.0")
}
```

#### 2. 适配新的API

StarX 0.6.0 引入了新的扩展系统API，如果你使用了内部API，可能需要进行适配。

#### 3. 检查依赖冲突

新版本添加了 Adventure API 的 `compileOnly` 依赖，请检查是否与你的项目存在依赖冲突。

#### 4. 更新配置文件

如果你使用了数据库配置，请检查 `DatabaseConfig` 的构造函数参数是否匹配。

# StarX 1.0.18

下载附件：`starx-universal-1.0.18.jar`。

整合 1.0.17 的共享平滑 Ping 与全网 GameProfile 快照优化，并补齐共享采样限频。

- 玩家列表按 250ms 调度；跨服 TAB 读取同一缓存，每玩家 250ms 内最多读取一次本地 Velocity Ping。仅开启跨服 TAB 时按现有 1 秒巡检持续采样，无需额外调度任务。
- 异常值不进入平滑窗口；最后有效样本超过 2 秒后显示未知，恢复时重置旧窗口。真实 0ms 样本仍有效。
- 平滑算法保持最近 5 个有效值的中位数与指数平滑；只读取 Player.getPing()，不增加网络探测。
- 全网快照缓存 GameProfile，减少各查看者创建条目时的重复代理查询。

验证范围包括采样限频、过期恢复、异常值、16 线程/1000 个模拟 UUID/160 万次采样压力测试，以及 Linux/Windows 全量 CI。上述为自动化测试，不代表真实 1000 名客户端联机验收。

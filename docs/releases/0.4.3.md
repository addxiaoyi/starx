# StarX 0.4.3

0.4.3 强化 SkinsRestorer 兼容性，公共扩展 API 仍为 1.0.0。

## SkinsRestorer 兼容性

- 兼容当前及旧版皮肤存储接口，运行时根据参数类型选择可用的 `setSkinData` 或 `setCustomSkinData` 写入方式。
- 皮肤查询按 UUID、玩家名和旧版参数签名提供回退路径，部分可选存储接口缺失时继续降级运行。
- 清理皮肤绑定时，在目标版本提供对应方法的情况下同步清理自定义皮肤数据；旧版本仍保留玩家绑定清理能力。
- 皮肤同步失败会返回明确的未应用状态，不再把兼容接口缺失静默当成成功。

## 升级

将 Velocity 和所有 Paper/Folia 实例替换为同一份 `starx-universal-0.4.3.jar`，完整重启后确认 Velocity 健康接口、后端 heartbeat、网站节点状态和 `StarX backend ready`。

同一实例不要同时放置 `starx-universal.jar` 与旧的 `starx-velocity.jar` 或 `starx-server.jar`。不支持 `/reload` 或插件管理器热替换。

## 验证

- `:starx-plugins:starx-common:test`：SkinsRestorer 存储接口和回退行为测试。
- `:starx-plugins:starx-server:test`：Paper/Folia 后端皮肤解析兼容性测试。
- `:starx-plugins:starx-universal:check`：Universal JAR 双平台描述符、API 边界和重复条目校验。
- 公共扩展 API 保持 1.0.0；生产部署和真实客户端验收需要按部署流程继续执行。

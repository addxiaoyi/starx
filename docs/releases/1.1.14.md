# StarX 1.1.14

Release asset: `starx-universal-1.1.14.jar`

## CPU and runtime resource control

- Ping sampling is disabled unless `%starx_ping%` or `%starx_ping_raw%` is configured.
- Cross-server TAB reconciliation is event-driven with a 5-second safety fallback.
- TAB writes are incremental and skipped when no visible field changed.
- Website texture scheduling is one-shot and follows the next due time instead of waking every two seconds.
- Runtime metrics expose player scans, TAB reconciles, TAB writes, and website request rates.

# StarX 1.0.24

修复后端桥接在玩家切服或断线瞬间抛出的 `IllegalStateException: Not connected to server!`。Velocity 在该情况下会直接抛异常而不是返回 false，现在按“无可用载体”处理，并新增回归测试覆盖断链场景。

同时记录本轮 FastLogin 真实正版链路排查结论：后端 `allowed-proxies.txt` 需要写入代理 `proxyId.txt` 中的 UUID，否则代理转发会被拒绝并反复出现 `No on-going login session`；FastLogin 的 Mojang 校验还需要服务器能够访问 `api.mojang.com`，网络不通时会记录 `Failed to check premium state` 并保持离线登录。

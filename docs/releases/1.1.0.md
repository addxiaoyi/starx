# StarX 1.1.0

## 皮肤同步性能重构

- 玩家进服时按真实 UUID 异步查询网站皮肤档案。
- 只允许一个有界皮肤查询线程和有限队列，重复 UUID 查询会合并。
- 切换后端服务器不会再次触发网站皮肤扫描。
- UUID 档案成功结果使用有界 LRU 缓存；404/未绑定结果不做负缓存。
- 默认关闭全量纹理 manifest 同步，自动配置不会因安装 SkinsRestorer 而重新开启。
- 移除网站同步路径中的历史玩家枚举和在线玩家全量纹理快照。
- 保留单玩家手动刷新入口，避免影响管理员主动处理皮肤异常。

## 发布文件

```text
starx-universal-1.1.0.jar
SHA256SUMS
release-manifest.json
```

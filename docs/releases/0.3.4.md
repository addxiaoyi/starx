# StarX 0.3.4

0.3.4 扩展后端运行矩阵到 Paper/Folia 26.1–26.2，并继续兼容原有 Minecraft 1.21 系列。公共扩展 API 仍为 1.0.0。

## 主要变化

- Minecraft 26.1.x 与 26.2.x 现在是正式认证范围。
- Java 25 现在是 Paper/Folia 26.x 的认证运行时；Java 21 继续作为 Universal JAR 字节码基线和旧后端运行时。
- 后端源码在发布时分别对 Paper `26.1.2.build.71-stable` 和 `26.2.build.84-stable` 编译。
- 26.3 及更新的同一 26.x 系列不会被严格门禁阻断，但会标记为 `DEGRADED`，直到完成对应实服验收。
- 保持 `api-version: '1.21'`，防止旧版 1.21 Paper/Folia 因描述符版本过高而拒绝加载。

## 兼容范围

- Java 21、25
- Velocity `3.5.0-SNAPSHOT` build 606
- Paper/Folia 1.21.0–1.21.11
- Paper/Folia 26.1.x–26.2.x
- Extension API 1.0.0

## 升级步骤

1. 备份每个实例的旧 JAR、配置和 Velocity StarX 数据库。
2. 将 Velocity 与所有 Paper/Folia 实例替换为同一个 `starx-universal-0.3.4.jar`。
3. Paper/Folia 26.x 实例使用 Java 25；Velocity 和旧 1.21 实例可继续使用 Java 21。
4. 完整重启后执行 `/starx doctor` 与 `/starxserver doctor`。
5. 在 26.1/26.2 后端确认 `StarX compatibility: SUPPORTED`、`StarX backend ready` 和 heartbeat 恢复。
6. 对高于 26.2 的 26.x 版本，先在 staging 验证后再投入生产。

## 验证

- Java 25 下的 Paper 26.1.2 与 26.2 API 编译门禁通过。
- 完整插件测试、发布元数据、Public API、扩展示例和 Universal JAR 校验通过。
- 发布后在生产 PVP Paper 26.1.2 实例执行真实加载、调度器、命令、heartbeat 和重启验收。
- Universal JAR 随 Release 提供 SHA-256 与发布清单。

朁来 26.x 版本的 `DEGRADED` 表示允许带告警启动，不代表已完成认证。

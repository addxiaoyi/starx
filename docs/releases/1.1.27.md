# StarX 1.1.27

Release asset: `starx-universal-1.1.27.jar`

## Health and operations

- Add `/starx health` for a consolidated view of website sync, circuit-breaker, HTTP pressure, backend heartbeat, EventBus, HTTP API, and cross-server TAB metrics.
- Add `/starx health <server>` for one backend's heartbeat, admission weight, bridge identity, platform, last-seen time, and capabilities.
- Publish backend, website-sync, circuit-breaker, runtime worker-queue, and HTTP concurrency pressure transitions to the incident timeline and webhook pipeline.
- Pair each reported fault with a recovery event using the same incident correlation ID. Repeated observations in an unchanged state do not generate more events.

## Resource bounds

- Keep Plan integration history bounded and thread-safe.
- Bound SmartAlert tracking with LRU eviction and avoid processing its own generated alert events.
- Bound per-IP tracking with sampled eviction and reset stale eviction cursors when the registry is cleared.

## Verification

- Release gate: `clean check :starx-plugins:starx-universal:check` passed on the 1.1.27 source snapshot.
- Local HTTP pressure tests use only loopback endpoints.
- Release assets include `starx-universal-1.1.27.jar`, `SHA256SUMS`, and `release-manifest.json`.
- Publication does not assert six-server deployment or production JVM reload; those are separate operational steps.

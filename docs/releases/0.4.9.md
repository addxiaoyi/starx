# StarX 0.4.9

`starx-universal-0.4.9.jar`

## 修复

- Yggdrasil 外部身份校验严格比较 UUID，不再通过简单玩家名片段判断正版身份。
- Premium、UniAuth 和网页登录兼容路径拒绝任意同名但 UUID 不一致的账号。
- 离线玩家兼容别名只接受确定性的 OfflinePlayer UUID，避免正版玩家与离线玩家被同名混淆。

## 验证

- common 与 velocity 测试通过。
- universal JAR 版本、双平台描述符和类边界由发布校验验证。

## 部署

将同一份 `starx-universal-0.4.9.jar` 放入 Velocity、Paper/Folia 各自的 `plugins/` 目录，保留旧 JAR 备份后完整重启对应 JVM。不要使用 `/reload` 或同时保留旧的分端 JAR。

# StarX 1.0.17

本版本继续降低全网 TAB 的网络与 CPU 开销。内置玩家列表、变量和跨服 TAB 现在共用同一份 Velocity 真实 Ping 平滑快照：250ms 采样、最近 5 次有效样本中位数、指数平滑，并拒绝负数及超过 10 秒的异常值。

跨服 TAB 不再独立持续读取和展示抖动的原始 Ping；只有平滑值变化达到阈值时才原位更新列表延迟。全网快照同时缓存玩家 GameProfile，避免在每个查看者的对账循环中重复查询目标玩家。

下载 `starx-universal-1.0.17.jar`，放入 Velocity 与 Paper/Folia 的 `plugins` 目录。

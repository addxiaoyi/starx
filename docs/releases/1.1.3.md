# StarX 1.1.3

## Deployment hardening

- Release verification runs the six-server deployment on the production self-hosted runner.
- Every server is updated serially with a pre-replacement backup and SHA-256 verification.
- The deployment uses the existing sudo path and does not restart Minecraft processes automatically.

## Release files

```text
starx-universal-1.1.3.jar
SHA256SUMS
release-manifest.json
```

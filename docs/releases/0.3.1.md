# StarX 0.3.1

0.3.1 是一次稳定化发布，重点是兼容性、配置升级、跨平台 CI、安全扫描和文档整理。公共扩展 API 仍为 1.0.0，没有破坏性 API 变更。

## 主要变化

- 运行时兼容性报告覆盖 Java、Velocity、Paper/Folia 和第三方软依赖。
- Spigot/CraftBukkit 不再被误判为 Paper。
- 新增 `/starx doctor` 与 `/starxserver doctor`。
- Paper/Folia 配置支持 schema、备份、原子迁移和未来版本拒绝。
- Gradle 9.6.1、Shadow 9.6.1。
- Ubuntu 与 Windows 执行完整 `clean check`。
- Trivy 构建后扫描最终 Universal JAR，并验证 Gson、HikariCP 和 SQLite JDBC 被识别。
- README 重新按功能、部署、兼容、命令和验证边界分类。

## 兼容范围

- Java 21
- Velocity `3.5.0-SNAPSHOT` build 606
- Paper/Folia 1.21.0–1.21.11
- Extension API 1.0.0

其他平台版本会根据运行时规则标记为 `UNKNOWN`、`DEGRADED` 或 `UNSUPPORTED`，不会自动宣称已认证。

## 升级

1. 备份现有 JAR、配置和数据目录。
2. 在 Velocity 与所有 Paper/Folia 实例中替换为同一个 `starx-universal-0.3.1.jar`。
3. 删除旧的 StarX 分端 JAR，避免重复插件 ID。
4. 先启动 Velocity，再启动后端。
5. 执行 `/starx doctor`、`/sxnodes status` 和 `/starxserver doctor`。
6. 核对自动配置、兼容性报告、heartbeat、网站同步和皮肤同步。
7. 完整重启一次，确认配置迁移和凭据持久化。

## 验证

- 701 项 Java 测试通过。
- Ubuntu 和 Windows CI 通过。
- Universal JAR 打包校验通过。
- Trivy 识别 5 个打包依赖；HIGH=0，CRITICAL=0。

自动化结果不等于生产实服验收。真实多 JVM、真实客户端、第三方插件组合、故障恢复和回滚仍需在部署环境完成。

# StarX 1.0.16

下载附件：`starx-universal-1.0.16.jar`

## 修复

- 跨服 TAB 默认开关已加入完整配置快照测试。
- 新安装生成的配置、运行时模块发现和发布门禁现在使用同一模块集合。

## 包含的 1.0.15 优化

- 任意子服可查看全网玩家，并显示独立配置映射后的子服前缀。
- Ping 仅在变化达到 5ms 时原位更新，不再因轻微波动移除并重建条目。
- TAB 刷新任务合并、单飞执行，并能恢复被后端覆盖的条目。
- 心跳命令邮箱始终报告真实零值指标。

## 验证

- Linux/Windows 全量 CI、Universal JAR 和发布元数据校验。

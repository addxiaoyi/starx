# StarX 0.4.5

0.4.5 是认证兼容性加固版本，公共扩展 API 仍为 1.0.0。

## 认证兼容性

- 本地密码和已验证身份统一经过 TOTP、风险校验与网页登录确认流程。
- 账号持久化 UUID 与当前连接 UUID 不一致时，登录后续流程按当前会话正确解析账号，覆盖 TOTP、恢复码和网页确认。
- 密码修改会完成本地凭据迁移状态，避免账号在不同认证路径之间反复切换。
- 外部认证服务不可用时不再伪装成密码错误，并继续拒绝未完成认证的连接。

## 升级说明

替换 Velocity 和所有 Paper/Folia 实例上的 `starx-universal-0.4.5.jar`，再按网络顺序重启。旧版 JAR 请保留备份；重启后确认 Velocity 健康接口、后端 heartbeat、网站节点状态和 `StarX backend ready`。

## 兼容性

公共扩展 API 保持 1.0.0。扩展应继续依赖公开 API 包，不要依赖 StarX 内部实现类或反射私有成员。

# StarX 0.8.0

## 下载

```text
starx-universal-0.8.0.jar
release-manifest.json
SHA256SUMS
```

同一 JAR 部署到 Velocity 和每个 Paper/Folia 后端，完整重启代理与后端，不要使用 `/reload`。

## 变更

- 后端踢出后的回退会排除刚失败的节点，并优先选择同类型、健康且未满的节点；没有可用节点时回退大厅。
- 认证流程仍保留其路由屏障，认证中的玩家不会被故障回退逻辑接管。
- 新增 `{starx_premium_display}` 与 `%starx_premium_display%`，展示验证中、正版、离线账户或未知。
- `/v1/network/status` 的 `metrics.playerNetwork` 包含本地平滑玩家 Ping P95 和样本数量，不会对玩家或后端发起额外探测。

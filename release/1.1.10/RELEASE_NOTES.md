# StarX 1.1.10 build assets

This directory contains the verified build for the closed website skin-delivery loop.

- `starx-universal-1.1.10.jar`: primary cross-platform plugin artifact.
- `starx-velocity-1.1.10.jar`: Velocity-specific artifact.
- `SHA256SUMS.txt`: SHA-256 checksums.
- `release-manifest.json`: release metadata.

The release signs official capes with the website skin when MineSkin supports the selected cape and falls back to SkinsRestorer URL resolution for URL-only skin profiles without adding a periodic scan.
